## Font metrics

The direct PDF export draws text with the 14 standard PDF fonts, which every
PDF reader provides; it embeds no font. To size the text, it carries the
character widths of these fonts (`src/export/pdf-metrics.ts`), taken from
Adobe's Core 14 AFM files: Copyright (c) 1985, 1987, 1989, 1990, 1991, 1992,
1993, 1997 Adobe Systems Incorporated. Their licence allows them to be used,
copied and distributed for any purpose, provided the copyright notices are
retained. Only the widths are used; the AFM files themselves are not
distributed.
